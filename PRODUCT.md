# NovaClient website

Public English-language presentation and download site plus a Discord-authenticated player account. Players prove an active PC-bound license using a temporary Diagnostics code, then choose their primary nickname through the same linking routine as the Discord bot. Profiles show real client-recorded stats, effective license role and assigned custom title. Public leaderboards show recorded totals; these are not official KoG rankings. Preserve black/purple identity, reduced-motion support, official distribution links and existing feature truth. No activation keys, device proofs or private credentials are public.

All visible account and leaderboard pages are hosted by GitHub Pages under https://novaclient.tech/account/. Only API and OAuth callback run on the license server. OAuth returns a one-use 90-second exchange code in a fragment; the Pages frontend exchanges it over HTTPS for a one-hour session in localStorage (shared across the site tabs, still limited by the server to one hour). CORS permits only the exact https://novaclient.tech origin. No session token is placed in a URL.

A single shared header is used by the landing, player account and leaderboard pages. Its account control reads authenticated identity without rotating form CSRF tokens; it displays the primary nickname and effective role when verified, and supports server-side logout.

Public ranking entries link to opaque player profile IDs. Public profiles expose only the displayed name, effective role, client-recorded stats, map attempts and the currently selected title; they never expose license numbers, Discord IDs or device proofs. Earned title names/colors are sourced from kog_stats_data.cpp, with effects from kog_stats.cpp. Custom titles must be enabled and assigned to the same license. A selected value of -1 displays no title, rather than substituting an arbitrary assignment. The client remains the source of title selection.
